## Hello, I'm Deshawn

### About Me
Final year Software Engineering student at Anglia Ruskin University with a focus on embedded systems, firmware development and also low-level programming. I enjoy learning how software interacts with hardware through practical projects as well as working with different microcontrollers, peripheral interfaces and anything I feel like experimenting with.

Currently I have been developing projects using a ESP32 with ESP-IDF whilst explaining my knowledge of C, RTOS concepts and embedded software architecture. I'm also exploring bare-metal development and the trade-offs between RTOS-based and resource-constrained systems.

My current goal is to presue Postgraduate study in embeddd system engineering and develop the skills needed to work on reliable, reasource constrained software but the main carrer goal is to work in embedded systems where it truly changes the world.
